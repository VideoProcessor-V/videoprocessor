## Plain-English Overview: What Temporal Detail v2 Does Visually & Functionally

- **What viewers will see once wired at Wave 4–6:** Compressed HDMI streams (Apple TV+, Netflix, cable, YouTube) give keyframes (I/P) far more detail than the B-frames between them, producing banded skies and dark walls, detail that softens and pulses between keyframes, and blocky colored edges. Temporal Detail v2 blends the **grain-free picture** of each frame with its motion-aligned past and future sharper peak frames (plus recurrent carry-forward), keeping every pixel adjustment inside what the received frame could have been before codec rounding, and returning the frame's **own untouched film grain** bit-for-bit.
- **Safety and cinema fidelity (Pass-2 Opus audit H1–H14 closed):**
  - **Honest drop-in visibility (H1):** Config card tooltips, `TdV2Settings.h` Ctrl+I status (`wiredToLiveRenderer = false` default), `MASTER-SETTINGS.md`, and `temporal_detail/README.md` all visibly state **"Temporal detail v2: library ready (not wired to live renderer yet — connects at Wave 4–6 integration)"**. `CoreSegments.inl` calls `TdProducts::ReadToday(TdProducts::Consumer::SigmaDelta)` directly so Sigma-Delta's TD fallback read is never stale when de-judder is off.
  - **Pass-1 face & non-rigid masking (H13):** Explicit per-cell `faceMask` / `faceMaskTex` input on both CPU and GPU forces **strictly zero delta** (`output == received` bit-for-bit, `StandInKind::FaceNonRigidMask` visible) on moving faces/non-rigid regions per Plan Q2 / §1.3 L127 / §3.3, while toggleable 3σ per-corner Huber bilinear tapering (`Config::enablePerCornerHuber`, wired with full CPU + GPU `Reference`/`RealTime` parity) enforces strict no-harm on unmasked organic micro-motion.
  - **Focus protection & matched-focus bokeh without self-vetoing curved skies (H8, Q4):** Genuine focal-plane shifts (`focusChange` along motion) hard-veto ALL bands (`L, M, H`, `kBandMask == 0`, `defocus false-restore <= 0.1%`), explicit matched-focus bokeh cells (`explicitDefocusedCells` / `kFocusMap` id 32, packed into GPU `cell_prior.y` bit 1) hard-veto `M, H` always and gate `L` strictly by `BokehMode` (`Untouched` = 0, `LowBandCellOnly` = 1), while static curved smooth gradients (`A·cos(2πx/96)` W1 skies) remain 100% unvetoed under default `BokehMode::Untouched`.
  - **No whole-frame blending without motion (H9):** Per Plan §1.2 L108 (L4), when a reference's motion field is null/missing (including carry without `carryMotion` and chroma `prevPeak`/`nextPeak`/anchor canvas without motion), the reference is skipped visibly (`StandInKind::MissingMotionNoWholeBlend` / `StandInKind::MotionFieldStandIn`) rather than blended as `"Still"` — zero ghosting on moving content across both luma and chroma.
