# Tests for `input.source_analysis (identity/)`

CPU-only unit tests, registered in `src/VideoProcessor-Test/VideoProcessor-Test.vcxproj.vcxproj`:

- `SourceIdConsensusTests.cpp`: dwell, hold on disagreement, flapping, stale votes, safety veto, per-axis Indicator port calls, the net's trust profile, minimum hold, ABR dwell, discontinuity, determinism and submission-order independence.
- `AbrStepDetectorTests.cpp`: ABR step detection on synthetic series (fixed-seed LCG, 4 samples per second of source time) and the one-time notice policy (`AbrNoticePolicyTests`).
- `SourceIdPipelineTests.cpp`: `SourceIdProductTests` (record codec, held-state holder, rebase applied once per generation, concurrent publish/read), `SourceQualityViewTests` (consensus off = the snapshot bit for bit; absent / stale / unlatched / recovered; every consumer has an absent-product path), `FrameQualityTests` (noise measure, RELATIVE quality), `SourceIdPipelineTests` (steady stream, rung drop detected + latched + noticed once with the rebase deferred, discontinuity re-arms, determinism), `SourceIdMonitorGateTests` (the monitor with consensus off / on without a record).
  SID-B0 additions in `SourceIdMonitorGateTests`: `ShadowDecidesLikeOffForAutoFactorsAndPublishes` (Off and Shadow monitors on the same synthetic tiles: AutoFactors, snapshot and quality view identical; the record is published and flagged shadow), `WouldBeLinesNameTheFieldTheChangeAndTheReason`.
- `SourceIdReplayTests.cpp` (SID-B0): the committed fixture `fixtures/srm-history-replay.csv` replayed through the pipeline (the writer's header, a deterministic trace, the changes today's consensus rules give: dwell, hold, veto, discontinuity; a missing column reported; a rotated session replays as one input; quoted notes).
- `../tests/SourceHistoryLogTests.cpp` (SID-B0): the session-long history writer (rotation to numbered files of one session, five sessions kept whole, bounded non-blocking queue with visible drops, a failed write reported once and recovered, no disk work in `Open`, quoted notes) and the monitor's rows (header first, every row full width, appended not rewritten).
- `SourceIdStreamingEvalTests.cpp`: machine-time evaluation on the streaming suite through the real monitor (consensus off and on lanes). SKIPS unless `VP_SOURCE_ID_EVAL_DIR` holds `reels.tsv` (see `tools/eval/source_id/`); writes `frames.csv`, `events.csv`, `engages.csv`, `notices.csv` for `replay.py`.

No GPU, no clocks. Run with `/Tests:SourceIdConsensusTests,SourceIdReplayTests,SourceHistoryLogTests,AbrStepDetectorTests,AbrNoticePolicyTests,SourceIdProductTests,SourceQualityViewTests,FrameQualityTests,SourceIdPipelineTests,SourceIdMonitorGateTests,ProductCatalogTests`. The streaming evaluation: `VP_SOURCE_ID_EVAL_DIR=<dir> ... /Tests:SourceIdStreamingEvalTests`, then `python -I tools/eval/source_id/replay.py --dir <dir>`.
