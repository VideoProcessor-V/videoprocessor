# DV display mapping: pre (RGB input) (`colour.dm_pre`)

Unit: **colour** | side: input | order: 85 | status: **built** | hook point: HOST

## Purpose / why

Post-decode I-only Dolby Vision debander (CF-DV P5): runs on the decoded PQ picture at `MAIN` (before libplacebo's colour map) using `shaders/vp_dm_pre_deband.glsl`. Debands strictly BT.2100 ICtCp intensity (`I`), leaving `Ct` and `Cp` untouched, preserving BTB/WTW without clamping, and guarding film grain with a spatial Laplacian/extremum veto.

## Design goal, philosophy and decisions

Built in CF-DV P5 from the VP-V DV display-mapping proposal (`docs/refs/125-dv-display-mapping-proposal.md`). Never performs a private decode: reads the shared D5 12-bit tap law (`DvTunnelGlsl.h`) and P14 coding quality (`VpDebander::Strength` at 12-bit depth / 4095 codes), engaging a visible `DV deband` fallback when either is absent or the shader fails to load. Off by default (`dv_post_decode_deband = off`) with zero hooks registered when inactive or on the Original pathway.
