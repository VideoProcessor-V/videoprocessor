# Tests for `repair.temporal_detail`

`TemporalDetailModelTests.cpp` (class `TemporalDetailModelTests`, in the VideoProcessor-Test project, CPU only) drives the CPU reference model on small synthetic scenes: an analytic textured master sampled at exact sub-pixel shifts (so the vectors are exact), a coding simulation per frame (an I-like frame keeps the master's fine band, a B-like frame attenuates it, patterns such as `IBBBPBBB`, irregular gaps or hierarchical), fresh grain per frame, and field or camera-view motion sources. It covers off identity, the I/B pulse, sub-pixel pans, focus pulls, rack focus, motion blur, occlusion, cuts and indicator stamps, determinism, grain, flicker and age-out, the future referee, irregular patterns, scale and rate generality, the camera adapter's fallback, the bounded fallback boost, the multi-frame template cleaner at the strict grain bounds (transform identity, gain vs the single-frame template) and settings parsing. The draft shaders are only compiled as a reference (the test includes `TemporalDetailShaders.h`); no GPU is used.
