# S2 shadow-ramp stack run

Generated by `python -I tools/eval/stack_runner.py --suite s2 --size-frac 0.125 --max-cases 6 --contexts sdr,hdr_pq,hdr_to_sdr`.

**Subset notice.** 6 of the suite's S2 cases (evenly spaced, deterministic) at size_frac 0.125 (480x270 px windows, 2 frames) to keep the run under 10 minutes of single-threaded CPU (measured 182 s). Full suite: `--max-cases 0 --size-frac 0.25`.

Stand-ins: s1 texture oracle, s2 VP deband model, s3 cr_gs contrast recovery (HDR->SDR only), s4 sigma-delta. `nd` = 8-bit rounding, no dither (scale reference); `+4` = sigma-delta final (amplitude 0.15). Every row ends 8-bit. band = mean-square coarse error in display PQ codes (lower is better); texture kept = projection ratio vs the plain chain with the same final step (nd vs plain nd, +4 vs plain+4; 1 = as plain, gate 0.97); grain ratio vs plain = cand/plain(same final) residual rms in display codes, vs master = cand/master (blank when the master has no grain); texture kept is blank when plain keeps < 0.25 of the master texture; btb = share of master pixels below black by more than half an output code step (2 ten-bit codes) whose output is still below black; wtw = share of master above-white pixels still above white. Values are means over the cases whose metric is defined; blanks = not applicable. Synthetic ramps contain no above-white; sigma-delta amplitude, stand-in strengths and the 2-frame length are deliberately simple, so read the tables as relative ordering only. The SDR coded input is already on the 8-bit grid, so plain+4 equals plain there (sigma-delta of an exact 8-bit signal is a no-op); texture-kept ratios are noisy where plain keeps little of the master texture.
